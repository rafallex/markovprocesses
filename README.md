# Markov Processes

Coursework from **MS012 Markov Processes** (period 3, year 1) of the M.Sc. in Image Analysis and Machine Learning at Uppsala University.

The course covered discrete- and continuous-time Markov chains, stationary distributions and long-run behaviour, classification of states, absorbing chains, and simulation methods. The code here is a mix of Python ports of the course's MATLAB examples and independent simulations I ran while working through the material.

## Notebooks

**`card_shuffling.ipynb`** — simulates a simple card-shuffle and measures how long it takes for the original bottom card to reach the top. An elementary example of mixing time for a Markov chain on permutations.

**`random_walks_recurrence.ipynb`** — simulates symmetric random walks on ℤ^d for dimensions 1–100. Estimates the return probability to the origin and compares it with the known values from Pólya's theorem (recurrent in d ≤ 2, transient in d ≥ 3). Includes path visualisations and plots of simulated vs. theoretical values.

**`markov_chain_and_ifs.ipynb`** — three short simulations:
1. A 3-state Markov chain simulator (Python port of the course's MATLAB code).
2. The Sierpinski triangle generated by the chaos game (IFS with three equally-weighted affine maps).
3. Barnsley's fern generated by a weighted IFS with four affine maps.

**`stationary_distributions.ipynb`** — computes stationary distributions by finding the null space of (P − I)ᵀ via SVD. Covers both the irreducible case (unique stationary distribution) and the reducible case with two absorbing classes (multiple stationary distributions).

## Project: The Secretary Problem as a Finite Markov Chain

Formalises the classical secretary problem as a finite Markov chain with absorbing states. Derives the transition matrix via Bayes' theorem and verifies it with the Chapman–Kolmogorov equation, then reproduces the analytical result that the optimal stopping threshold converges to t* ≈ n/e and corroborates it through Monte Carlo simulation.

See `project/Secretary_Problem_as_an_MC.pdf` for the written report.
